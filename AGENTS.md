# AntarktidaUI agent guide

For product UI or component work in this repository, read `skills/astracat-design-system/SKILL.md`. When composing or integrating Twig templates, also read `skills/astracat-twig-ui/SKILL.md`.

Use `design-system/tokens/index.css` as the foundation entrypoint. Reuse component and pattern APIs from `design-system/components/` and `design-system/patterns/`; document any reusable primitive in `design-system/docs/components.md`. The standalone `index.html` is the visual documentation page. This repository currently has no Twig runtime or build pipeline.

Keep changes within the user's requested scope. Do not infer permission to publish, deploy, or change external services from the presence of this guide.
